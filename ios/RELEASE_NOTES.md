映流 iOS / iPadOS 0.9.2

- 每个新视频（包括上下滑切换）都从“宽度适屏”开始，不再沿用上次的适屏模式
- 下载速度常驻在顶部标题下方，随 HUD 一起显示、隐藏
- 九宫格手势设置改成手机屏幕图示：每个区域的单击 / 双击 / 长按 / 拖动放在对应位置，点一下即可更换；带“恢复默认”
- 进度条：手指按住直接拖动，不再需要长按等待；单纯点按不跳转；去掉圆点，白线为已播放、灰线为未播放
- 左右拖动新增“精细进度调整（±10 秒）”：以当前时间为中心，拖动半个屏幕宽度 = 10 秒，HUD 显示偏移量，松手精确定位

未签名 IPA，需要用 Feather / AltStore / Sideloadly / TrollStore 或自己的证书重签。iPhone 与 iPad 通用，最低 iOS / iPadOS 16。播放器为系统 AVPlayer，仅支持 MP4 / MOV / M4V / 3GP。
