映流 iOS / iPadOS 0.9.1

- 中文名改为“映流”
- 添加 SMB 服务器：“共享名”改为“路径”，示例 `/share`；可直接填 `/share/子目录`，不再单独填共享内根目录
- 标记页可直接删除服务器上的原文件（左滑或长按 → 删除文件，需确认），删除后自动取消标记
- 新增固定下载地址和 Feather / AltStore 源，便于签名后检查更新

未签名 IPA，需要用 Feather / AltStore / Sideloadly / TrollStore 或自己的证书重签。iPhone 与 iPad 通用，最低 iOS / iPadOS 16。播放器为系统 AVPlayer，仅支持 MP4 / MOV / M4V / 3GP。
