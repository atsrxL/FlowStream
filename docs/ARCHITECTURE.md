# 架构与交互决策

## 需求消歧


“中区长按正常播放”：解释为按住期间临时 1×，并临时从暂停状态播放；松开后恢复长按前的状态和常用倍率。“左滑倒退 0.1 倍”解释为左滑进入 0.1× 反向回看，继续左移逐步增至 2×，而不是按一次就减小正向倍率。

“小窗”：实现系统 PiP，而不是申请 SYSTEM_ALERT_WINDOW 的自由悬浮窗。

“上下滑切换”：上滑下一条，下滑上一条；文件夹当前排序形成播放队列；主动切片从目标条目开头播放；只在退出并选择历史时续播。文件播完循环本文件；队列边界不首尾相接。

“单击暂停”（0.2.0 覆盖之前仅显示菜单的行为）：播放器空白／视频内容区短触切换暂停／继续并显示控件，系统边缘及已显示的交互控件除外。上、中、下三区仅约束长按，普通轻触和纵滑覆盖三区。

## 分层和线程

UI、ExoPlayer 操作和手势状态在主线程。SQLite 访问和 Keystore 密码存取走 `FlowApp.disk` 单线程；网络目录读取、连接关闭走有限的 `FlowApp.io` 工作线程。播放数据读取由 Media3 加载线程调用 `DataSource`。

MainActivity 的请求带 generation token，来源、目录或页面改变后，过时的回调不替换现有结果。列表适配器使用结果快照，避免异步刷新时数据量与 ListView 状态不一致。Intent 只传 session ID，不把最多 10,000 条队列放入 Binder。

每个播放器持有一个 SourceBundle。SMB 路径通过虚拟 URI `smbx://server-id/relative-path` 定位；真实主机、密码不进入媒体 URI。SmbPool 在一个播放器内复用连接，但不同服务器配置之间不共享认证。播放器先 release，再由工作线程关闭传输。

WebDAV 使用同一受限 OkHttp 配置处理目录和播放请求。网络拦截器对实际请求（含重定向和分片）检查来源与根路径，只为合规请求附加认证。非零 Range 收到整文件 200 响应时报错。完整媒体响应校验及坏服务器互操作尚待联调，不能当作对任意不规范服务器的完全兼容实现。

## 手势状态机

```text
IDLE --DOWN--> PENDING
PENDING --短触松手--> TapResolver 等待单双击确认 --> IDLE
PENDING --原始/自定义模式 + 超过死区--> PAN
PAN --MOVE--> 平移并夹紧（绝不切片）
PAN --UP/CANCEL--> IDLE
PENDING --纵向占优且超过死区--> VERTICAL
VERTICAL --UP + 距离/速度/轴向/冷却通过--> 前后切片 --> IDLE
PENDING --380ms + 位移未越界 + 中区--> HOLD_MIDDLE
PENDING --380ms + 位移未越界 + 下区--> HOLD_BOTTOM
PENDING --未长按横滑 / 大角度斜滑 / 上区长按--> REJECTED
HOLD_* --UP/CANCEL/第二指/焦点变化/旋转/PiP--> 恢复先前状态 --> IDLE
```

纵滑和长按一旦判定不能相互转换。长按后纵向漂移不切片；手指跨三区边界不改变按下时的区域；微小纵向滑动松手不会再误识别为单击。`cancel()` 幂等，一次长按最多触发一次恢复。

方向提示只预览，不提前提交切片。判定阈值按 dp 和区域高度组合，减少不同分辨率设备上的偏差。系统边缘不请求手势排除，保留平台导航行为。

## 0.2.0：单双击、双指和纹理几何

`TapResolver` 不在第一下触摸时暂停。第一下短触后按系统双击窗口调度确认；第二下在时间／距离窗口内进入候选，必须第二次短触松手才切换尺寸。第二次拖动、长按或多指取消候选，故没有“先暂停再恢复”的音频闪断。点击工具栏会取消尚未生效的图像单击。系统无障碍 `performClick` 仍执行一次正常暂停／继续。

`GestureMachine.down(..., inspectMode)` 在 DOWN 固定本次是否为查看画面模式。原始／自定义模式下越过死区进入 PAN，而非 VERTICAL；未移动的中、下区长按照旧。长按一旦建立，拖动用于原来的速度／反向回看；不能再移动画面。即使在画面边界，PAN 也不会改判切片。适屏才可上下滑切片，原始模式也可点击底部上一条／下一条。

`GestureOverlay` 通过 `ScaleGestureDetector` 接收完整事件流，禁用 double-tap quick scale 和笔按钮缩放。第二指 DOWN 立即结束临时播放状态、撤销待确认单击和纵滑，进入多指独占。抬到一指时重绑定剩余 pointer ID 并重置拖动起点，可继续平移；直至全部抬起才允许新一轮点击、长按和换片。第三指加入由 ScaleGestureDetector 重新建立尺度，不复用旧单指速度。

`VideoViewport` 全部几何按渲染像素计算：显示宽度 = VideoSize.width × pixelWidthHeightRatio × scale，高度 = VideoSize.height × scale。FIT = min(窗口宽/显示源宽, 窗口高/源高)，原始尺寸 scale = 1。视频旋转已由 Media3 处理，不再使用 Format 的原始编码宽高重复旋转。两轴分别以居中或覆盖窗口的范围夹紧；普通方形像素原始模式的平移原点对齐整数渲染像素。

`flow_video.xml` 在构造时选用 `texture_view` 和 `resize_mode=fill`。`VideoTransformController` 只给纹理设置 Matrix：sx=显示宽/纹理视图宽，sy=显示高/纹理视图高，tx/ty=计算出的左上角。这样宽高比只处理一次，不把整个 PlayerView（控件、字幕、触摸分区）一起放大；也不重新分配帧位图。PlayerView 1.9.3 官方源码已检查，不自行调用 TextureView.setTransform 覆盖应用矩阵。该源码核对不是设备渲染测试。

新视频、窗口尺寸改变、方向／PiP 和分辨率变更恢复适屏；重复的相同 VideoSize 不重置，同一条 EOS 循环没有主动重置。缩放与偏移暂不持久化。纹理路径不能保证低分辨率系统合成后的物理面板 1:1，也不能声称与 SurfaceView 具有同等 HDR、功耗和帧时序。

## 倍率和反向模式

常用速度与临时速度分离。菜单共有 46 档，用整数百分位构造，再转成 float，避免逐次相加导致 2.00 之后出现意外的 2.05。下区长按可使用连续手势的 0.05 档位，松手不将临时值保存成菜单常用速度。

反向模式用独立 ReverseClock 积分目标位置，不依据每次 seek 返回的关键帧位置继续计算，防止反复舍入后位置卡住。时间增量有上限，主线程长暂停不会一次跳回很远。播放器正缓冲时不继续送 seek；该设计限制请求频率，但不是逐帧反向解码器。

0.05× 暂时禁用音轨；离开该档时重新允许音轨。轨道变化时重新确认正向倍率；这仍是待设备验收的实现路径。

## 生命周期

入场锁定当前朝向，用户明确点击旋转后才变更。配置变化不重建播放器，取消正在进行的手势和拖动，重算触摸区域。Android 16 大屏暂时允许限制方向的 manifest property 已加入；这不是对所有厂商、折叠设备和未来 targetSdk 的永久保证。

`onPause` 保存状态并取消临时交互，不直接把 PiP 播放暂停；`onStop` 才暂停释放。普通后台回来重建播放器并从内存／会话记录恢复。MediaSession 提供系统播放状态，小窗由系统管理。没有播放前台服务，后台不可见不持续播放。

暂停状态下长按临时播放，松开仍回到暂停；音频焦点丢失或耳机断开触发暂停时，取消临时播放恢复，避免长按结束重新抢播。进度条拖动中断也清理拖动状态。

## 数据和安全

会话和队列表通过外键级联删除；历史按更新时间限制最近 100 条。保存间隔 5 秒；会话清除后 checkpoint 只更新，不复活删除记录。服务器记录删除不会删除历史，使旧会话能被看到并明确提示来源不可用。

密码为 AES-GCM 密文，AAD 是服务器 ID；用户名、地址和历史不加密。禁用应用备份并防止密码编辑窗口被普通截屏；不声称可抵御已 root、系统级采集、恶意输入法或调试内存提取。

WebDAV XML 限体积，拒绝 DTD/实体，限制命名空间、成功 propstat 和直属子项；路径拒绝父级穿越、编码分隔符、控制字符，保留中文、空格、加号和百分号。目录适配器只返回文件夹和媒体候选文件。

SMBJ 的 `list()` 先由库构建列表，再检查 10,000 项限制，因此不能声称扫描任意巨大 SMB 目录时完全恒定内存。没有第三方完整依赖扫描和安全审计结果。
