# 0.2.0 播放器操作规则

以下描述对应本版源码，尚未完成 Android 真机验收。

## 常用动作

| 动作 | 结果 |
| --- | --- |
| 单击画面／黑边 | 播放中暂停，暂停中继续；同时显示原有菜单。单击需等待系统双击窗口（通常约 300ms），避免双击时先暂停。 |
| 双击适屏画面 | 切到原始尺寸，以点击位置为缩放焦点；超出边界时自动夹紧。不会改变播放状态。 |
| 双击原始／自定义画面 | 恢复适应屏幕并居中。 |
| 双指开合 | 按双指中心缩放。最高 max(8×适屏, 原始尺寸)，最低 min(适屏, 原始尺寸)；松手后接近适屏会吸附。 |
| 原始／自定义模式直接拖动 | 单指平移，可横、竖、斜向。到边界停止，绝不转为换片。 |
| 适屏时上下滑 | 上滑下一条，下滑上一条，延续 0.1.0 的死区、轴向和冷却规则。 |
| 中区静止长按 | 临时 1×正常播放；按住左移进入 0.1×至 2×反向回看（仍是离散 seek）。 |
| 下区静止长按 | 临时 2×；按住左移降至 1×、右移增至 5×。 |
| 长按结束 | 恢复长按之前的播放／暂停和常用速度。 |

系统导航边缘和已经显示的按钮优先，不属于全屏手势区域。上中下三区按整个播放器的屏幕高度划分，不跟随被放大或拖动的视频。

## 先拖动，还是先长按

原始／自定义模式下，先移动超过死区则拖画面；先原地保持 380ms 则进入相应区域的长按播放控制。任一模式成立后不切换到另一个模式。上区没有长按动作，停住太久后这次手势会被拒绝，需重新按下拖动。

缩放查看期间可点击菜单的上一条／下一条，或先双击恢复适屏再上下滑。换新视频从适屏开始；缩放不继承到下一条。

## 多指和单双击防误触

第二指按下时，先结束已有的长按变速／反向回看，并撤销单击候选和纵滑，再进入缩放。松到剩余一指可继续拖；该指不能立刻触发长按、暂停或换片，必须全部抬手后开始新动作。

双击第二次必须是合格短触松手，不能在第二次按下时就放大。如果第二次变成长按、滑动或双指，则取消单双击候选，不补发延迟暂停。焦点丢失、系统 CANCEL、工具栏操作、转屏和 PiP 也会清掉待确认单击。

## 点对点究竟指什么

普通方形像素视频的原始尺寸 scale=1：例如当前解码轨为 3840×2160，画面矩形就是 3840×2160 个应用渲染像素，窗口放不下时裁切查看并可拖动。若视频只有 640×360，而适屏曾将它放大，切原始尺寸会缩小，而不是继续放大。

非方形像素会进行显示比例校正，不能同时保证两轴逐编码像素 1:1；界面不会对它标注严格“1:1”。系统对整个应用低分辨率合成再放大的设备，也无法保证面板物理像素点对点。判定真实像素表现需要目标设备、已知 1px 测试视频和不被二次缩放的截图。

旋转、PiP、窗口尺寸或视频分辨率变化后恢复适屏；同条视频结束循环不主动重置。缩放参数暂不写入会话历史。
