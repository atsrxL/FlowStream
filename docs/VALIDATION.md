## 可复现命令

在项目根目录：

```bash
bash tools/test-core.sh
java tools/JavaSyntaxCheck.java app/src/main/java core/src/main/java core/src/test/java
python3 tools/test_fixture.py
python3 tools/check-project.py
bash -n tools/build.sh tools/test-core.sh
```

Android 环境准备好后，必须另外执行：

```bash
bash tools/build.sh
# 默认要求核心、lint、assembleDebug 全部成功。
```

## 真机验收清单（全部尚待执行）

以下是预期，不是已通过的测试记录。建议覆盖 Android 8/12/16、小屏手机及 Android 16 大屏设备；同一项同时测试横屏和竖屏。

| 场景 | 预期 / 检查点 |
| --- | --- |
| 首次安装、启动、权限 | 无崩溃；不要求广泛存储访问或覆盖其他应用权限；无服务器时提供设置入口。 |
| SMB2/3 认证、加密 | 正确只读账号可浏览并播放；密码错误、SMB1-only、要求加密但服务器不支持时明确失败。 |
| WebDAV 基础 | PROPFIND 207，HTTP 显式启用，HTTPS 校验，中文／空格／加号文件可播；非零 Range 返回 206。 |
| WebDAV 错误 | 401/403、无 Range、404、错误证书、越域重定向、根外分片均不泄漏认证、不假装成功。 |
| 长片随机定位 | 大于 4GiB 文件可从较远位置续播和定位；不先下载整片；断网重试保持播放器界面。 |
| 会话历史 | 多服务器切换、关闭重进、系统杀进程、删除当前文件、清除历史；临时速度不污染常用速度。 |
| 普通轻触 | 三个区域单击均暂停／继续并显示菜单，双击不改变播放状态，暂停时菜单常驻；滑动小于换片阈值不意外切片；可见按钮独立生效。 |
| 原始尺寸 | 3840×2160 视频在 1080px 宽窗口，不按固定 2×缩放；方形像素原始模式宽度 3840 个渲染像素。用 1px 棋盘／细线测试片和无缩放截图检查，而非仅看 HUD。 |
| 低分辨率原始尺寸 | 640×360 视频在高分辨率手机双击后可能缩小，居中显示；再次双击恢复适屏。 |
| 双击误触防护 | 首击后立即接横滑、纵滑、长按、双指、旋转、工具栏按钮，不出现延迟暂停或突然缩放。 |
| 原始尺寸拖动 | 横向、纵向、斜向均可拖；两轴独立限制，不能拖出整屏空白；边界处继续拖不会切片；静止长按仍变速。 |
| 双指缩放 | 焦点跟随双指中心；开合范围、适屏吸附、同时平移不异常；单击仍可暂停，双击回适屏。 |
| 多指交接 | 双指抬起一指后继续拖，不能立刻长按／切片／暂停；第三指加入、指针 ID 重排、抬指顺序、CANCEL 均不出现跳动和残留动作。 |
| 缩放状态 | 同条循环保留；不同视频（含相同分辨率）重置；旋转／PiP／自适应分辨率切换复位，菜单和三区不放大。 |
| 渲染兼容性 | TextureView 在目标设备上的 HDR、功耗、帧时序、低分辨率合成、黑边透明性和小窗都需要单独验收。 |
| 纵向换片 | 上下一次各切一条；45° 斜滑、未长按横滑、<64dp 快甩和系统边缘不切片；首尾有提示。 |
| 连续快速滑动 | 450ms 冷却有效，不跨多条、不产生失控网络加载。 |
| 中区长按 | 临时 1×；左滑 24dp 开始 0.1× 回看，继续左移最高 2×；回到原点附近恢复临时 1×。 |
| 中区回看边界 | 0 秒停住；缓冲期间不堆积定位；长 GOP 和慢网络视觉表现可接受，并明确近似定位性质。 |
| 下区长按 | 临时 2×；±12dp 微抖不变；左滑至 1×、右滑至 5×；长按期间上下漂移不切片。 |
| 手势中断 | 第二指、来电／音频焦点、耳机拔出、系统导航、旋转、进入 PiP、按 Home，均不留下卡住的加速／静音状态。 |
| 暂停后的长按 | 按住临时播放，松手恢复暂停；不会因焦点丢失后松手重新抢播。 |
| 速度菜单 | 46 档精确，2× 之后直接 2.5×；分别测 0.05× 静音和 5× 的实际视频时间变化，不只看 UI 文案。 |
| 单条循环 | 视频尾部直接从头播放，不退出 Activity，不自动进入队列下一条；无 EOS 卡死。 |
| 旋转和锁定 | 进入保留原朝向，不随横竖视频自动转屏；显式按钮改变朝向，播放进度不丢；大屏上检查平台限制。 |
| PiP | 允许 / 禁止权限、进入 / 展开 / 关闭、横竖视频比例、返回文件页再打开另一条、系统媒体控制；无双播放器抢音频。 |
| 资源和稳定性 | 连续换片与往返 PiP，观察解码器、连接、线程、内存；测高码率、发热、电量、弱网以及服务端离线。 |
