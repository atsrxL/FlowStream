# FlowStream 0.4.1

## 上下滑切片问题

设备当前活动来源保存了原始尺寸偏好。旧实现按整个播放器的缩放模式仲裁触摸，原始尺寸或自定义缩放时，连黑边的拖动也被用于平移画面，因此无法切片；移除上一条/下一条按钮后更难发现恢复入口。

修复：
- 在按下时判断是否位于实际视频矩形内。缩放时画面内拖动继续平移，黑边上下滑可以切片；手势开始后不改变归属，拖出画面也不会中途切片。
- 新增圆形“适屏”按钮，恢复适屏及来源偏好，重新启用画面区域上下滑。
- 恢复原始尺寸时显示画面拖动与黑边切片提示。
- 按用户要求清理不再需要的协议解释及参考链接。此前发布的历史压缩包保持原样，新版源码包不含这些文字。
