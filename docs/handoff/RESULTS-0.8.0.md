# FlowStream 0.8.0 · 映流 ODS 布局

设计来源：用户 `/Users/at/Documents/映流.ods`，Sheet1；原文件保持不变。

## 实现

- A1、D1、E1：旋转、小窗、全局播放速度；以五列等宽对齐。
- C2：临时状态、操作说明或加载速度；状态提示优先显示，不叠加。
- A5:E10 / A11:E16 / A17:E22：三个等高区域。上区长按倒放；中区双击切换尺寸、横拖进度；下区单击HUD、双击播放暂停、长按快进。空白动作不绑定。
- A24/E24：媒体信息、菜单，外部点击关闭。删除仍为确认后删除原文件。
- A25:E25：−10s、−3s、播放／暂停、+3s、+10s；移除可见A/B按钮。
- A26 / B26:D26 / E26：锁、常驻进度条、当前／总时长。拖动时预览位于进度条上方。
- 三个区域的单击、双击、长按、横拖均可配置。双指缩放后仅平移；任一区域双击恢复宽度适屏。
- 长按默认倒放1×、正播2×；左右1cm映射至0.1–5×端点，松手恢复全局速度与播放状态。
- HUD隐藏时间0–30秒，0常驻；下一条预读0–50MB，可选应用临时目录或内存。
- RAM预读真实接入播放，缓存前缀后从缺失字节继续读取上游；当前／下一条共享50MiB上限。内部磁盘缓存可跨进程复用，系统可能回收；RAM随进程结束消失。

屏幕按实际可用宽高适配，手势区域避开顶部状态与底部控件，不要求表格行高逐像素复刻。横向系统返回手势边缘保留。
