# FlowStream 0.8.1

依据2026-09-14更新的 `/Users/at/Documents/映流.ods`；原文件未修改。

## 变更

预览不再每个目标重建提取器和网络连接；播放、下条预读、预览各自独立。预览内部保留最多3条范围读取流、32个256KiB数据块（最多8MiB），复用视频头和已读帧数据。拖动请求每120ms合并，当前解码完成后继续最新目标；旧目标完成帧仍可作为临时预览，不因持续MOVE事件全部丢弃。当前媒体就绪后预热预览。缩放提取失败时尝试完整关键帧再缩小。

原代码的问题包括300ms延迟在每次MOVE重置、每次请求重建连接和提取器、单数据块来回替换视频头/帧数据。新实现消除上述重复工作。这里的多流是独立范围读取连接复用，并非同时多路解码；最大3条，不无限增加网络请求。

按表格最新G15/G21，中区和下区横拖实时定位主播放画面，100ms合并定位请求，松手精确定位，取消恢复起点；F32的放大状态下底部进度条仍可拖动并显示独立缩略图。B24增加标记按钮，主页增加标记列表。标记跨进程保留，打开时重新读取原文件夹建立队列，删除原文件/来源配置同步移除标记。随机播放顺序仍只在当前进程保留。

状态文案改为“快进 2×”“快退 1×”“宽度适屏”等，去掉HUD中的操作指导与实现说明。
