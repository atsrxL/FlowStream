## 应用更新

九区控制采用三行等高、20%/60%/20%列宽。上排默认无绑定；中排统一长按快退、单击HUD、横拖进度，双击为−1秒/适屏/+1秒；下排统一长按快进、单击HUD、横拖进度，双击为−1秒/播放暂停/+1秒。各区四类动作可配置，使用新九区配置键。

横拖实时更新主画面、进度条上方缩略图及顶部C2时间。松手精确定位，取消恢复起点。自定义缩放内仅平移和双击宽度适屏；底部进度条仍可拖动并保留缩放。

HUD设置1–10秒；视频预读50–3072MB。磁盘用filesDir/video-cache持久保存，LRU按所选容量限制；清空按钮异步取消预读并清除持久缓存及旧版临时视频缓存。内存按实际堆空间限制，设置显示可用预算；3GB是配置上限，未承诺在手机堆中分配3GB。
