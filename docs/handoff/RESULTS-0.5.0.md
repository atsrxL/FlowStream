- 文件浏览页：浅色背景、大标题、圆角封面、底部导航。缩略图模式固定双列，名称在封面下；单列模式封面在左、文字在右。

## 仍存在的边界

- 指定开始区域内按住约380ms才生效；从系统导航边缘或可见按钮按下优先交给系统/按钮。
- 单击、双击需等待系统连击窗口；三击不会额外播放暂停。
- 高度适屏/宽度适屏可能裁掉另一轴内容，这是指定预设的比例行为；想拖动观察须双指进入缩放状态。
- 未提取到封面时保留占位，持久缓存可手动清除；替换同路径同大小文件后需清缓存。
- 逐帧按钮是帧率估算定位，回看是离散seek。HDR、变帧率精确控制、弱网和长时间功耗仍需扩展验收。
