# FlowStream 0.6.0

已编译并通过 ADB 192.168.123.140:5555 安装到 MI 9，Android 15。

## 本次变更

- 文件夹使用独立黄色矢量图标，列表/双列均支持。双列文件名继续位于缩略图下方。
- 移除收藏、书签、历史界面与写入。升级时清除旧记录；当前播放队列与随机顺序只在进程内保留。服务器、文件夹、速度和主题设置仍保留。
- 设置提供黑、白、跟随系统。文件页、设置、对话框按主题显示；播放器保持黑底。
- 顶部只保留一行：旋转、退出、小窗、速度。
- 底部三行：info（再点关闭）；时间/进度条；锁、-10s、-2s、播放、+2s、+10s、A/B。尺寸模式仍用三击切换。
- 进度条需静止长按后拖动，短按不定位。拖动显示目标时间及邻近关键帧；松手提交，取消不提交，保留原播放/暂停状态。
- 网络取帧改为256 KiB有界读取及块复用，避免反复打开整段剩余数据。
- 保留原有加载速度、预读、切片、缩放、临时速度及AB速度继承。
